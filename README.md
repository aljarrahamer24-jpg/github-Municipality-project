# منصة إدارة شكاوى وطلبات خدمات البلدية

مشروع تخرج — منصة رقمية لاستقبال شكاوى وطلبات المواطنين ومتابعتها حتى الإغلاق، بثلاثة أدوار: **المواطن**، **موظف البلدية**، **مدير البلدية**.

> **المرحلة الحالية: تصميم UI/UX فقط.**
> لا يوجد Backend أو قاعدة بيانات أو مصادقة حقيقية. كل البيانات المعروضة تجريبية (Mock Data) من `assets/js/data.js`.

## التقنيات
- **HTML** — صفحة مستقلة لكل شاشة.
- **CSS** — ملف واحد منفصل: `assets/css/style.css`.
- **JavaScript** — ملفات منفصلة في `assets/js/` (بدون أي إطار عمل).
- **بدون Node.js وبدون npm وبدون أي خطوة بناء (Build).**
- مكتبة الخرائط Leaflet والأيقونات (Lucide) محفوظة محلياً داخل المشروع.
- خط IBM Plex Sans Arabic من Google Fonts. بدون إنترنت يُستخدم خط Tahoma بديلاً.
- واجهة عربية RTL بالكامل، ومتجاوبة مع الموبايل والتابلت والكمبيوتر (Mobile First).

## التشغيل
افتح الملف **`index.html`** مباشرة في المتصفح (نقرتان). لا يحتاج أي تثبيت.

- ابدأ من **`screens.html`** لرؤية فهرس جميع الشاشات الـ 34.
- أو من **`auth/login.html`** واختر الدور (مواطن / موظف / مدير).
- يمكن التبديل بين الأدوار من قائمة المستخدم أعلى أي لوحة.
- صور الخرائط تحتاج اتصالاً بالإنترنت.

> اختياري: يمكن استخدام إضافة **Live Server** في VS Code لإعادة تحميل الصفحة تلقائياً أثناء التعديل.

## هيكل المشروع
```
├── index.html              الصفحة الرئيسية
├── track.html              متابعة بلاغ برقم المتابعة
├── screens.html            فهرس جميع الشاشات
├── design-system.html      نظام التصميم (عرض حي للمكونات)
├── auth/                   تسجيل الدخول، إنشاء حساب، نسيت/إعادة تعيين كلمة المرور
├── citizen/                واجهة المواطن (7 صفحات)
├── employee/               واجهة الموظف (4 صفحات)
├── admin/                  لوحة المدير + التحليلات + إدارة النظام (15 صفحة)
├── assets/
│   ├── css/style.css       ملف التنسيق الوحيد (المتغيرات، المكونات، التخطيطات، التجاوب، الطباعة)
│   ├── js/
│   │   ├── icons.js        الأيقونات (SVG)
│   │   ├── data.js         البيانات التجريبية
│   │   ├── ui.js           الأدوات والمكونات المشتركة + بناء الهيدر والقوائم
│   │   ├── charts.js       الرسوم البيانية (SVG)
│   │   ├── maps.js         الخرائط (Leaflet)
│   │   └── pages/          ملف JavaScript لكل صفحة
│   ├── vendor/leaflet/     مكتبة الخرائط (نسخة محلية)
│   └── img/favicon.svg
└── docs/                   التوثيق
```
