# 2. مسارات المستخدمين (User Flows)

## 2.1 المواطن

```mermaid
flowchart TD
    H["الصفحة الرئيسية"] -->|تقديم بلاغ| LOGGED{"مسجل دخول؟"}
    H -->|متابعة بلاغ| TR["/track إدخال رقم البلاغ"] --> TRR["حالة البلاغ + Timeline"]
    LOGGED -->|لا| L["تسجيل الدخول"]
    L -->|لا يملك حساب| R["إنشاء حساب"] --> DASH
    L -->|نسي كلمة المرور| F["نسيت كلمة المرور"] --> FM["تحقق من بريدك"] --> RP["إعادة التعيين"] --> L
    L --> DASH["لوحة المواطن"]
    LOGGED -->|نعم| W1

    DASH -->|إنشاء بلاغ جديد| W1["1. نوع المشكلة"]
    W1 --> W2["2. العنوان + الوصف + الصور"]
    W2 --> W3["3. الموقع على الخريطة + الحي"]
    W3 --> W4["4. المراجعة (مع أزرار تعديل لكل خطوة)"]
    W4 -->|إرسال البلاغ| OK["شاشة النجاح + رقم البلاغ"]
    OK --> DET

    DASH -->|آخر البلاغات| DET["تفاصيل البلاغ"]
    DET --> CM["إضافة تعليق"]
    DET -->|الحالة = مغلق| RATE["تقييم الخدمة 1–5 + تعليق"] --> THX["شكراً لتقييمك"] --> DASH
    DASH --> NOTIF["الإشعارات"] --> DET
```

**نقاط تجربة الاستخدام الأساسية:**
- زر "بلاغ جديد" متاح دائماً: في الشريط العلوي (سطح المكتب) وزر دائري عائم في منتصف الشريط السفلي (موبايل).
- النموذج مقسّم لـ 4 خطوات قصيرة مع شريط تقدم، والتحقق من الحقول يظهر عند محاولة الانتقال فقط.
- زر "التالي" ثابت أسفل الشاشة على الموبايل لسهولة الوصول بالإبهام.
- المواطن لا يرى الملاحظات الداخلية للموظفين.

## 2.2 موظف البلدية

```mermaid
flowchart TD
    L["تسجيل الدخول"] --> D["لوحة الموظف: 5 بطاقات إحصائية"]
    D --> T["جدول البلاغات"]
    T -->|بحث / فلترة / ترتيب / تبويبات الحالة| T
    T -->|اختيار بلاغ| DET["تفاصيل البلاغ"]
    D -->|بطاقة المتأخرة| T
    DET --> V["مشاهدة البيانات + الصور + الموقع + Timeline"]
    DET --> ACT["لوحة الإجراءات"]
    ACT --> S["تغيير الحالة / الأولوية / القسم / الموظف"]
    S -->|الحالة = تم الحل| UP["رفع صور بعد المعالجة (إلزامي)"]
    S --> NOTE["ملاحظة تحديث (تظهر للمواطن)"]
    UP --> SAVE["حفظ التحديث → إشعار المواطن"]
    NOTE --> SAVE
    DET --> IN["إضافة ملاحظة داخلية (لا تظهر للمواطن)"]
    D --> MAP["خريطة البلاغات"] --> DET
```

## 2.3 مدير البلدية (Admin)

```mermaid
flowchart TD
    L["تسجيل الدخول"] --> D["لوحة المدير: 6 KPIs + 4 Charts + أحدث البلاغات"]
    D -->|تنبيه طقس| W["الاستعداد للحالات الجوية"]
    W --> W1["المناطق الحساسة + خريطة المخاطر"] --> W2["قائمة الاستعداد + إرسال تنبيه للفرق"]
    D -->|تنبيه تكرار| RC["المشاكل المتكررة"] --> RC1["عرض البلاغات المرتبطة (Modal)"] --> DET["تفاصيل البلاغ"]
    D --> MAP["خريطة البلاغات"] --> MAP1["فلاتر: النوع / الفترة / المنطقة / الحالة"] --> MAP2["Markers / Heatmap + المناطق الساخنة"]
    D --> REP["التقارير الشهرية"] --> REP1["اختيار الشهر → إنشاء"] --> REP2["Preview"] --> REP3["Print / Export PDF"]
    D --> SAT["رضا المواطنين"] --> KW["الكلمات المفتاحية"]
    D --> ALL["جميع البلاغات"] --> DET
    D --> SYS["إدارة النظام"]
    SYS --> CRUD["المستخدمون / الموظفون / الأقسام / أنواع المشاكل / المناطق / الكلمات المفتاحية"]
    CRUD --> M1["إضافة / تعديل (Modal)"]
    CRUD --> M2["حذف (Modal تأكيد)"]
    SYS --> SET["إعدادات النظام"]
```

## 2.4 دورة حياة البلاغ (الحالات)

```mermaid
stateDiagram-v2
    [*] --> جديد
    جديد --> قيد_المراجعة
    قيد_المراجعة --> مرفوض
    قيد_المراجعة --> قيد_المعالجة: إحالة للقسم
    قيد_المعالجة --> تم_الحل: رفع صور بعد المعالجة
    تم_الحل --> مغلق: تأكيد / إغلاق تلقائي
    مغلق --> [*]: تقييم المواطن
    مرفوض --> [*]
```

"متأخر" ليست حالة مستقلة، بل **علامة (flag)** تظهر عندما يتجاوز البلاغ المدة المحددة (SLA) لنوع المشكلة وهو ما زال مفتوحاً.
