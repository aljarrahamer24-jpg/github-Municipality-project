# 7. طبقة الذكاء الاصطناعي

طبقة إضافية فوق النظام الحالي، ولم يُستبدل أو يُحذف منه أي شيء.

**المبدأ الأساسي:** قاعدة البيانات هي مصدر الحقيقة، والذكاء الاصطناعي يقترح فقط:

| يحدده النظام (قاعدة البيانات أو الجهاز) | يقترحه الذكاء الاصطناعي |
|---|---|
| رقم البلاغ، الحالة، القسم، الأولوية الرسمية، الموعد النهائي | نوع المشكلة |
| **الموقع (GPS الجهاز أو الخريطة)** | عنوان ووصف مقترح بالعربية |
| كشف التكرار: مسافة حقيقية + نوع + حالة | درجة الاستعجال (للمراجعة فقط) |
| الإحصائيات والأرقام | وصف المكان إذا ذكره المواطن نصاً |

## 7.1 البنية

```
المتصفح (assets/js/core/ai.js)
   │  sb.functions.invoke('ai', { action, ... })   ← لا مفاتيح في المتصفح
   ▼
Supabase Edge Function  (supabase/functions/ai/index.ts — TypeScript)
   │  1. التحقق من الجلسة والدور        (_shared/db.ts)
   │  2. حد الطلبات لكل مستخدم           (ai_begin_request)
   │  3. التحقق من المدخلات
   │  4. المهمة                          (_shared/ai/complaint.ts)
   │  5. المزوّد عبر واجهة موحدة          (_shared/ai/provider.ts → gemini.ts)
   │  6. التحقق من المخرجات وحفظها        (ai_analyses)
   ▼
قاعدة البيانات (بصلاحيات المستخدم نفسه عبر RLS — بدون Service Role)
```

- **تغيير المزوّد مستقبلاً:** أضف ملفاً ينفّذ الواجهة `AIProvider` داخل `_shared/ai/`، ثم اضبط المتغير `AI_PROVIDER`. لا حاجة لتعديل الواجهة أو الميزات.
- **الإدخال الصوتي:** يتم في المتصفح عبر Web Speech API، وهو مجاني ولا يحتاج مفتاحاً. يعمل في Chrome وEdge. إذا لم يدعمه المتصفح، يكتب المواطن النص بنفسه.

## 7.2 المرحلة 1 (منفّذة): البلاغ الذكي + كشف التكرار

| الميزة | الوصف |
|---|---|
| 📷 البلاغ بالصورة | يصوّر المواطن المشكلة، فتُصغَّر الصورة في المتصفح ثم تُحلَّل. يُقترح النوع والعنوان والوصف ودرجة الاستعجال، وتُرفق الصورة بالبلاغ |
| 📝 البلاغ بالنص بالعامية | مثل "عمود الكهربا عند الدوار مش شغال"، ويُستخرج منه نفس ما سبق، ووصف المكان إن ذُكر |
| 🎤 البلاغ بالصوت | يتحول الكلام إلى نص في المتصفح، ثم يحلَّل كالنص |
| 📍 الموقع | من GPS الجهاز فقط، مع اقتراح أقرب منطقة. إذا رُفض GPS يحدد المواطن الموقع على الخريطة |
| 🔁 كشف التكرار | قبل الإرسال: بحث عن بلاغ **مفتوح** من **نفس النوع** ضمن **50 متراً** (مسافة Haversine حقيقية) |
| ➕ "نعم، نفس المشكلة" | لا يُنشأ بلاغ جديد. تُسجَّل مساهمة المواطن مع ملاحظته وصوره على البلاغ الموجود، ويُشعر الموظف، ويُشعر المساهم عند كل تغيير حالة |
| 👁️ للموظف | يظهر في صفحة البلاغ: اقتراح الذكاء الاصطناعي، وعدد المواطنين الذين أكدوا المشكلة، وملاحظاتهم |

الخطوات للمواطن: **صوّر أو تحدث** ثم **راجع** ثم **أرسل**.

### الجداول والدوال الجديدة
الملف: `supabase/migrations/20260930000000_ai_phase1.sql`، وكلها إضافات فقط.

| العنصر | الوظيفة | الصلاحيات |
|---|---|---|
| `ai_analyses` | كل تحليل (المدخل، النتيجة، المزوّد، النموذج) مع ربطه بالبلاغ | صاحبه، وموظف قسم البلاغ. لا يمكن تعديله |
| `ai_requests` | سجل الطلبات لحد الاستخدام (20 طلباً في الساعة افتراضياً) | قراءة الصاحب فقط، والكتابة عبر الدالة فقط |
| `complaint_contributions` | تأكيدات المواطنين لبلاغ موجود | صاحبها، وموظف القسم. الإضافة عبر الدالة فقط |
| `find_nearby_complaints()` | البلاغات المفتوحة القريبة | تُعيد النوع والحالة والمسافة فقط، بدون عنوان أو وصف أو اسم (خصوصية) |
| `confirm_duplicate()` | تسجيل المساهمة | تعيد التحقق من المسافة في الخادم، وتمنع تأكيد بلاغك أو بلاغ مغلق |
| `app_settings.ai` | `enabled`، `max_requests_per_hour`، `duplicate_radius_m` | المدير |

## 7.3 الإعداد في مشروعك (مرة واحدة)

1. **قاعدة البيانات:** نفّذ `supabase/migrations/20260930000000_ai_phase1.sql` في SQL Editor.
2. **مفتاح Gemini المجاني:** من [Google AI Studio](https://aistudio.google.com/app/apikey) اضغط **Create API key**. لا تضعه في أي ملف داخل المشروع.
3. **نشر الدالة:** يحتاج [Node.js](https://nodejs.org) على جهازك لتشغيل أداة Supabase فقط، وليس كخادم للمشروع. نفّذ في Terminal داخل مجلد المشروع:
   ```bash
   npx supabase login
   npx supabase link --project-ref lrlriimsfscgritbcqjs
   npx supabase secrets set GEMINI_API_KEY=ضع_المفتاح_هنا
   npx supabase functions deploy ai --no-verify-jwt
   ```
   الخيار `--no-verify-jwt` لا يلغي الحماية: الدالة نفسها تتحقق من الجلسة عبر Supabase Auth في كل طلب. هذا الخيار مطلوب لتعمل مع المفاتيح الجديدة (publishable).

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `GEMINI_API_KEY` | نعم | مفتاح Google Gemini (سرّي، في Supabase Secrets فقط) |
| `GEMINI_MODEL` | لا | الافتراضي `gemini-3.1-flash-lite` (ضمن الطبقة المجانية) |
| `AI_PROVIDER` | لا | الافتراضي `gemini` |

**قبل النشر:** كل الميزات القديمة تعمل كما هي. أزرار الذكاء الاصطناعي تعرض رسالة واضحة، والمواطن يكمل يدوياً. كشف التكرار يعمل بدون الذكاء الاصطناعي بعد تنفيذ ملف SQL فقط.

## 7.4 الخصوصية والموثوقية

- الطبقة المجانية من Gemini قد تستخدم البيانات لتحسين خدمات Google. لذلك لا نرسل إلا الصورة ونص المشكلة وقائمة الأنواع، بدون اسم أو هاتف أو إحداثيات. الواجهة توضح ذلك للمواطن.
- مخرجات الذكاء الاصطناعي تُفحص في الخادم: يجب أن يكون النوع من القائمة الموجودة، وتُقص الأطوال وتُزال الرموز. إذا لم يتأكد النموذج من النوع يُترك فارغاً ويختاره المواطن.
- **عند أي فشل** (خدمة متوقفة، تجاوز الحد المجاني، نتيجة غير صالحة): تظهر رسالة عربية ويُكمل المواطن البلاغ يدوياً، وتبقى صورته في النموذج.
