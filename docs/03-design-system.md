# 3. نظام التصميم (Design System) والهوية البصرية

جميع القيم معرّفة كـ Design Tokens داخل `src/index.css` (كتلة `@theme` في Tailwind CSS v4)، وتُستخدم في الكود كـ classes مثل `bg-primary-700` و`text-ink-2` و`rounded-card`. صفحة العرض الحي: **`/design-system`**.

## 3.1 الألوان

### Primary — أخضر مؤسسي (Teal)
يوحي بالثقة والاستقرار والطابع الحكومي، ومرتبط بالبيئة والمدينة الخضراء.

| 50 | 100 | 200 | 300 | 400 | 500 | 600 | **700 (الأساسي)** | 800 | 900 |
|---|---|---|---|---|---|---|---|---|---|
| `#effaf7` | `#d5f1ea` | `#aee2d6` | `#7ccbbb` | `#47ad9b` | `#28917f` | `#1a7467` | **`#0b5d51`** | `#0a4a42` | `#093d37` |

الاستخدام: الأزرار الرئيسية، الروابط، العنصر النشط في القوائم، الشعار.

### Secondary — ذهبي رملي
لمسة تراثية للإبراز: زر "تقديم بلاغ" في الواجهة العامة، النجوم، الشارات المميزة.

| 50 | 100 | 200 | 300 | 400 | **500 (الأساسي)** | 600 | 700 |
|---|---|---|---|---|---|---|---|
| `#fbf7ef` | `#f4ead3` | `#e8d3a6` | `#dbb872` | `#d1a250` | **`#c8963e`** | `#a97630` | `#87592a` |

### الألوان الدلالية (Semantic)

## 3.2 الخط
**IBM Plex Sans Arabic** (Google Fonts) — خط رسمي حديث، واضح على الشاشات الصغيرة، وله نسخة لاتينية متناسقة للأرقام ورموز البلاغات.

| النمط | الحجم / الوزن |
|---|---|
| Display (Hero) | 36–48px / 700 |
| عنوان صفحة | 24px / 700 |
| عنوان بطاقة | 16–18px / 600 |
| نص أساسي | 14–16px / 400 |
| نص صغير (تواريخ، تلميحات) | 12px / 400 |

الأرقام لاتينية (`ar-u-nu-latn`) كما هو معتمد في أغلب المنصات الحكومية، وأرقام البلاغات تُعرض بـ `tabular-nums`.

## 3.3 الزوايا (Border Radius)
| Token | القيمة | الاستخدام |
|---|---|---|
| `sm` | 6px | عناصر صغيرة |
| `md` | 10px | الأزرار والحقول |
| `lg` / `card` | 14px | البطاقات |
| `xl` | 20px | النوافذ المنبثقة والأقسام الكبيرة |
| `full` | — | الشارات (Badges) والصور الرمزية |

## 3.4 الظلال
| Token | الاستخدام |
|---|---|
| `shadow-xs` | الأزرار |
| `shadow-card` | البطاقات (ظل خفيف جداً + حد 1px) |
| `shadow-pop` | القوائم المنسدلة، التلميحات، العناصر العائمة |
| `shadow-modal` | النوافذ المنبثقة |

## 3.5 الأزرار
| النوع | الاستخدام |
|---|---|
| Primary (أخضر ممتلئ) | الإجراء الرئيسي في الصفحة — واحد فقط لكل منطقة |
| Accent (ذهبي) | الدعوة لاتخاذ إجراء في الواجهة العامة + التقييم |
| Secondary (أخضر فاتح) | إجراءات ثانوية مهمة |
| Outline | تصدير، طباعة، إلغاء |
| Ghost | إجراءات خفيفة داخل الجداول والبطاقات |
| Danger (أحمر) | الحذف والإجراءات الخطرة (دائماً مع تأكيد) |

الأحجام: `sm` 36px، `md` 44px (الحد الأدنى لمنطقة اللمس)، `lg` 48px. تدعم أيقونة قبل/بعد النص، وحالة `loading` و`disabled`.

## 3.6 البطاقات (Cards)
خلفية بيضاء، حد `line` بسمك 1px، زوايا 14px، `shadow-card`. رأس البطاقة (`CardHeader`) يحتوي عنواناً + وصفاً اختيارياً + إجراء على الطرف المقابل، مفصول بخط.

**بطاقة الإحصائية (StatCard):** عنوان + رقم كبير + أيقونة داخل مربع ملون + مؤشر اتجاه (أخضر إذا كان التغيير جيداً، أحمر إذا كان سيئاً — مع أيقونة سهم وليس اللون فقط).

## 3.7 الحقول (Inputs)
- ارتفاع 44px، حد `line-strong`، زوايا 10px.
- عند التركيز: حد أخضر + هالة `ring-4 primary-100`.
- عند الخطأ: حد أحمر + رسالة أسفل الحقل.
- التسمية دائماً فوق الحقل، والنجمة الحمراء للحقول الإلزامية، والتلميح أسفل الحقل.
- دعم أيقونة داخل الحقل، وزر إظهار/إخفاء لكلمة المرور.
- حقول الهاتف والأرقام تُكتب `dir="ltr"`.

## 3.8 الجداول
- رأس بخلفية `muted` ونص 12px عريض.
- صفوف بفواصل أفقية فقط، وتظليل عند المرور، والصف بالكامل قابل للنقر.
- أعمدة قابلة للترتيب مع أيقونة ↕.
- فوقها: تبويبات الحالة + بحث + فلاتر، وأسفلها: عدد النتائج + ترقيم الصفحات.
- **على الموبايل تتحول إلى بطاقات** (لا تمرير أفقي).
- حالة فارغة (Empty State) مع زر "مسح الفلاتر".

## 3.9 شارات الحالات (Status Badges)
كل شارة = **لون + أيقونة + نص** حتى لا يُعتمد على اللون وحده (إمكانية الوصول لمن لديهم عمى ألوان).

| الحالة | اللون | الأيقونة |
|---|---|---|
| جديد | أزرق Info | دائرة بنقطة |
| قيد المراجعة | بنفسجي | عدسة بحث |
| قيد المعالجة | برتقالي Warning | مؤشر تحميل |
| تم الحل | أخضر Success | علامة صح |
| مغلق | رمادي | قفل |
| مرفوض | أحمر Error | علامة X |
| متأخر (علامة إضافية) | أحمر | مثلث تحذير |

**الأولوية:** منخفضة (رمادي) · متوسطة (أزرق) · عالية (برتقالي) · عاجلة (أحمر) — مع نقطة ملونة.

## 3.10 إمكانية الوصول (Accessibility)
- تباين نصوص يتجاوز 4.5:1 على الخلفيات.
- `focus-visible` واضح على جميع العناصر التفاعلية.
- `aria-label` للأزرار التي تحتوي أيقونة فقط.
- مناطق لمس لا تقل عن 40–44px.
- النوافذ المنبثقة تُغلق بـ Esc وبالنقر خارجها.
