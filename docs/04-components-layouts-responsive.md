# 4. المكونات المشتركة، التخطيطات (Layouts)، والسلوك المتجاوب

## 4.1 مكونات UI المشتركة

المشروع مكتوب بـ **HTML + CSS + JavaScript فقط** (بدون Node.js وبدون أي إطار عمل). كل مكوّن له:
- **تنسيق CSS** في `assets/css/style.css` (قسم "4. المكونات").
- وعند الحاجة **دالة JavaScript** في `assets/js/core/ui.js` تُرجع HTML جاهزاً أو تضيف السلوك التفاعلي.

### الرسوم البيانية — `assets/js/core/charts.js` (SVG مكتوب يدوياً، بدون مكتبات)
| الدالة | الاستخدام |
|---|---|
| `Charts.hbar(el, data)` | أعمدة أفقية (النوع / القسم / المنطقة) |
| `Charts.columns(el, data, { key })` | أعمدة عمودية لسلسلة واحدة |
| `Charts.area(el, data, series)` | خطوط + مساحة لسلسلتين (المستلمة / المغلقة) |
| `Charts.line(el, data, { domain })` | خط لسلسلة واحدة (الرضا الشهري) |

كلها تدعم Tooltip عند المرور، وتعيد الرسم تلقائياً عند تغير عرض الشاشة، والزمن يتجه من اليمين لليسار.

### الخرائط — `assets/js/core/maps.js` (مكتبة Leaflet محلياً في `assets/vendor/leaflet`)
| الدالة | الاستخدام |
|---|---|
| `Maps.location(el, lat, lng)` | عرض موقع بلاغ واحد |

### كيف يُبنى التخطيط؟
كل صفحة HTML تحتوي فقط على محتواها داخل `<main id="content">`، وتحدد نوعها في `<body>`:

```html
<body data-layout="admin" data-active="reports" data-root="../">
```

- `data-layout`: نوع الواجهة (`public` / `auth` / `citizen` / `employee` / `admin`).
- `data-active`: عنصر القائمة المميز.
- `data-root`: المسار إلى جذر المشروع (`""` أو `"../"`).

عند التحميل يستدعي ملف الصفحة `App.page({ roles: [...] }, init)` من `core/app.js`، والذي:
1. يتحقق من الجلسة (Supabase Auth). إذا لم يكن المستخدم مسجلاً وتطلبت الصفحة دوراً، يُحوَّل لصفحة الدخول.
2. يقرأ ملف المستخدم من `profiles`. إذا لم يكن دوره مسموحاً للصفحة، يُحوَّل للوحته مع رسالة.
3. يبني الهيدر والقائمة الجانبية (`core/layout.js`) ببيانات المستخدم الحقيقية.
4. يشغّل الإشعارات اللحظية (`core/notifications.js`).
5. ينفّذ دالة الصفحة `init`، ويعرض رسالة خطأ عربية مع زر "إعادة المحاولة" عند أي فشل.

### حالات الصفحة
| الحالة | طريقة المعالجة |
|---|---|
| تحميل | `loadingBlock()` داخل كل بطاقة، ومؤشر عام حتى التحقق من الجلسة |
| خطأ / انقطاع الشبكة | `showError()` برسالة عربية وزر إعادة المحاولة |
| لا توجد بيانات | `empty()` برسالة واضحة وإجراء مقترح |
| نجاح | `toast()` |
| غير مصرح | تحويل للوحة المستخدم مع رسالة |
| انتهاء الجلسة | تحويل لصفحة الدخول برسالة "انتهت الجلسة" |

كل الأخطاء تمر عبر `toAppError()` في `core/supabase.js`، التي تحوّل رسائل Supabase إلى رسائل عربية مفهومة.

## 4.2 التخطيطات (Layouts)

### Public Layout — الواجهة العامة
```
┌──────────────────────────────────────────────┐
│ [الشعار]    الرئيسية  الخدمات  ...   [دخول][حساب] │  ← Header ثابت (Sticky)
├──────────────────────────────────────────────┤
│                 محتوى الصفحة                  │
├──────────────────────────────────────────────┤
│  Footer: عن المنصة | روابط | الدعم | تواصل      │
└──────────────────────────────────────────────┘
```
موبايل: القائمة تتحول إلى زر ☰ يفتح Drawer من اليمين.

### Auth Layout — المصادقة
```
┌───────────────────────┬──────────────────────┐
│  [الشعار]              │                      │
│                       │   لوحة الهوية         │
│    نموذج (max 448px)   │   (خلفية خضراء +      │
│                       │    مزايا المنصة)       │
└───────────────────────┴──────────────────────┘
```
موبايل/تابلت: النموذج فقط بعرض كامل، وتختفي لوحة الهوية.

### Citizen Layout — المواطن
```
┌──────────────────────────────────────────────┐
│ [الشعار]  لوحتي  بلاغاتي  الإشعارات  حسابي  [+ بلاغ جديد] [👤] │
├──────────────────────────────────────────────┤
│              المحتوى (max 1280px)              │
└──────────────────────────────────────────────┘
موبايل:
┌──────────────────────┐
│ [الشعار]      🔔 [👤] │
│       المحتوى         │
├──────────────────────┤
│ لوحتي بلاغاتي (+) إشعارات حسابي │ ← Bottom Tab Bar + زر عائم
└──────────────────────┘
```
المواطن مستخدم غير متخصص، لذا اخترنا تنقلاً علوياً بسيطاً بدلاً من Sidebar، وشريطاً سفلياً على الموبايل كتطبيقات الهاتف.

### Dashboard Layout — الموظف والمدير
```
┌────────────────────────────────┬─────────────┐
│ [بحث سريع]          🔔 📊 [👤]  │  [الشعار]    │
├────────────────────────────────┤  الرئيسية    │
│                                │  البلاغات    │
│         المحتوى                 │  ─ التحليل ─ │
│                                │  ...         │
│                                │  ─ الإدارة ─ │
└────────────────────────────────┴─────────────┘
                                  Sidebar 260px (يمين — RTL)
```
- Sidebar داكن بمجموعات (الرئيسية / التحليل والذكاء / إدارة النظام) مع عدادات.
- أقل من 1024px: يختفي الـ Sidebar ويظهر زر ☰ يفتحه كـ Drawer.
- قائمة المستخدم تعرض الاسم والدور الحقيقيين، ورابط لوحة التحكم، وتسجيل الخروج. جرس الإشعارات يعرض آخر الإشعارات لحظياً.

## 4.3 السلوك المتجاوب (Responsive — Mobile First)

نقاط التوقف (Media Queries في style.css): `sm` 640px · `md` 768px · `lg` 1024px · `xl` 1280px · `2xl` 1536px

| العنصر | موبايل (< 768) | تابلت (768–1023) | سطح المكتب (≥ 1024) |
|---|---|---|---|
| التنقل العام | Drawer | Drawer | روابط أفقية |
| تنقل المواطن | شريط سفلي + زر عائم | روابط علوية | روابط علوية |
| Sidebar اللوحات | Drawer | Drawer | ثابت 260px |
| بطاقات الإحصائيات | عمودان | 3 أعمدة | 4–6 أعمدة |
| جداول البلاغات | **بطاقات** | جدول | جدول |
| فلاتر الجدول | مخفية خلف زر "الفلاتر" + عداد | مخفية خلف زر | ظاهرة في صف واحد |
| نموذج إنشاء بلاغ | عمود واحد، أزرار ثابتة أسفل الشاشة، يظهر اسم الخطوة الحالية فقط | عمود واحد | نموذج + ملخص جانبي |
| تفاصيل البلاغ (موظف) | **لوحة الإجراءات أولاً**، ثم البيانات، ثم Timeline | نفس الموبايل | عمودان: المحتوى + الإجراءات/Timeline |
| الرسوم البيانية | عرض كامل، عمود واحد | عمود واحد | عمودان |
| الخرائط | ارتفاع 420px | 420–560px | 560px + لوحة المناطق الساخنة جانبية |
| النوافذ المنبثقة | Bottom Sheet من الأسفل | وسط الشاشة | وسط الشاشة |
| التقارير | ورقة بعرض كامل | — | ورقة A4 بعرض 896px في المنتصف |

**قواعد عامة:**
- لا تمرير أفقي للصفحة على أي عرض (تم التحقق آلياً على 390px و1440px لكل الشاشات).
- مسافة جانبية 16px على الموبايل، و24–32px على الشاشات الأكبر.
- منطقة اللمس لا تقل عن 40px، والأزرار الرئيسية 44–48px.
- احترام `safe-area-inset-bottom` لأجهزة iPhone في الشريط السفلي.
- الطباعة: إخفاء الـ Sidebar والـ Header والأزرار (`.no-print`) وطباعة التقرير فقط.
